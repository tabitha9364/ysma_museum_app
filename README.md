# YSMA Smart Museum Experience

A cross-platform mobile application developed for the Yemisi Shyllon Museum of Art (YSMA), featuring AR artwork recognition, interactive exhibit exploration, personalized onboarding, secure authentication, and interactive exhibit exploration.

## Overview

The YSMA Smart Museum Experience was developed as a final-year project at Pan-Atlantic University. The application combines mobile development, user-focused interface design, database integration, and AI-assisted functionality to create a more interactive way for visitors to engage with museum artworks.

The application was built with Flutter and Dart, with Supabase and PostgreSQL supporting backend and data functionality. TensorFlow Lite and Google Teachable Machine were also used as part of the intelligent artwork interaction workflow.

## Key Features

- AR artwork recognition
- Personalized onboarding experience
- Secure user authentication
- Interactive artwork and exhibit exploration
- Responsive Flutter user interface
- Personalized user profiles
- Intelligent artwork interaction
- Multi-module mobile navigation
- Android production build
